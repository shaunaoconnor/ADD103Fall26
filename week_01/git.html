Git & GitHub

1. Understanding Git and GitHub

Git is a distributed version control system that helps developers track changes in their code. GitHub is a platform that hosts Git repositories and provides tools for collaboration and code management.

2. My Source Control Process

First, I create a new branch for each feature or bug fix. Then, I make changes to the code and commit them with meaningful commit messages. Finally, I push the changes to the remote repository on GitHub and create pull requests for review.
